# Nexus Docker

A comprehensive Docker Compose setup for Nexus Repository Manager with PostgreSQL backend, Traefik reverse proxy, and automated repository provisioning.

## Quick Start

⚠️ **SECURITY FIRST**: This setup requires secure credential generation before use.

```bash
cd nexus-docker
make credentials  # Generate secure passwords (REQUIRED)
make start        # Start all services
make setup        # Accept EULA and configure Nexus
make test         # Validate repository functionality
```

🔐 **Security Features:**

- **No default passwords** - `admin123` is never used
- **Cryptographically secure** random password generation
- **Credential isolation** - Files excluded from version control
- **Fail-safe deployment** - Services won't start without credentials

## Configuration

### Environment Variables

The system uses a `.env` file for configuration, which is automatically generated by `make credentials`:

```bash
make credentials  # Generates .env with secure passwords
```

**Configuration Options:**

- **`.env.example`** - Template with all available configuration options
- **`.env`** - Generated configuration with secure credentials (git-ignored)
- **`.nexus-credentials`** - Secure credential storage (git-ignored)

**Key Configuration Areas:**

- **Security**: Admin credentials, SSL/TLS settings
- **Network**: Ports, domain names, proxy settings
- **Resources**: Memory limits, heap sizes
- **Features**: Repository types, backup settings, logging
- **Development**: Debug options, test mode

**Customization:**

```bash
# Edit generated .env file to customize
vim .env

# Or start fresh from template
cp nexus-docker/.env.example .env
# Then run: make credentials
```
